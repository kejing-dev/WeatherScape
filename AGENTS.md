# 天气境 WeatherScape: project guidance

A tabletop weather diorama for PICO OS 6 Shared Space (Spatial SDK BOM 6.1.9), package `io.embodit.weatherscape`, v0.1.2.
Design contract: spatial-app-factory `apps/weather-scape/design-package.json` (v1.0, gate B passed 2026-11-12 with all
defaults: turn the brass ring through 48 h + tap cloud / tree / house; Open-Meteo, CC BY, non-commercial; Shared Space,
archetype A, 生产力; stone house A + birch + island A + lamp, procedural vane; no photos / immersive env (v2); 48 h only;
window offset 3–5° accepted, DV4). Skeleton from the factory's puzzle-box (CloudAir lineage: two containers, theme,
sound pool, board-input template); weather data, ring, scene and pages are new.

## Surfaces
- **Diorama volume** (default container `WeatherScapeVolume`, Volumetric 0.66 x 0.54 x 0.68 m, fixed scale, gravity
  aligned, uniform resize). Walnut plinth Ø 0.40, a flat brass time ring (48 h on 330°, a stop pin in the 30° gap,
  engraved hour ticks / local clock hours / day names, all a runtime texture), a brass readout (display only, two lines)
  with its pointer, the "面板 / Panel" knob; Tripo island + stone house + birch + lamp (calibrated in
  `domain/ModelCalib.kt`, generated by `tools/calibrate_models.py`), procedural clouds (≤ 6), rain / snow sheets (4 each,
  one merged mesh per sheet sliding on a 5 cm lattice), fog bands, smoke, snow shell (5 k-triangle island copy), roof
  snow, vane, sun / moon on the arc, window / lamp glows (emissive only, no point lights), pond ripples, one ask tag.
  One directional key light (N3 works) + a global brightness factor on every PBR base colour.
- **Control window** (`WeatherScapeControl`, Planar 760 x 660 dp fixed (v0.1.2), `Placement.right(volume)`): native SpatialUI
  `TabBar`, three pages 天气 / 城市 / 设置; first run shows the how-to card on the weather page. No page scrolls.
  [退出应用] closes both containers, removes the tasks and ends the process. The app never reads the head pose.

## v0.1.2 (gate B C1-C5 + user 11-13 on the headset)
White clouds / smoke / fog / flakes: `domain/Controls.kt WhiteLook` (emissive base >= 40 % of the colour, light greys only;
white PBR rendered near black in the Shared Space volume on the headset). 3D ◀ ▶ brass buttons on the ring's front left /
right (`Names.STEP_BACK / STEP_FWD`, holders with collider + HoverEffect, greyed at 0 h / the end, push-in 4 mm); press =
1 h, held 4 h/s after 0.45 s, release stops (`HourHold`, `WeatherFlow.holdStart / holdEnd / holdTap / stepHour`); the
board-input template gained `onPress / onRelease`. Control window 760 x 660 dp: row 1 read-only "📍 city · time" + mute,
row 4 = 8 clickable 6-hour blocks (`StripMath`) with the clock ticks and day names on the strip's bottom edge, row 5 =
[◀ 1 小时] [回到现在] [1 小时 ▶] (native Buttons, press / release via interactionSource). Ring drag kept as an extra
(`// gate:allow shared-drag`). Screenshots: `tools/ws.sh shot` now uses the spatial screencap (5120 x 2880 -> 2560 x 1440 +
a `-panel` crop of the window), the 760 dp window leaves the current-view frame.

## v0.1.1 (QA #1 rework)
Smoke yields to every ask tag (`domain/Smoke.kt`); 16 dp between side-by-side buttons; the how-to card teaches both the
ring and the 48 h strip tap (D53, Shared Space kept); search: Chinese characters search in Chinese, hits ranked exact
name > capital / seat > population, English names filled via /v1/get; fog = soft wisp rings; snow flakes carry a white
emissive; cities page area 340 dp (no-result / offline = compact note + your cities). Source: github.com/kejing-dev/WeatherScape.

## Code
| Path | What |
|---|---|
| `domain/Weather.kt` | Sky (WMO mapping), Hour, Slice, units, wind levels / Beaufort / compass |
| `domain/OpenMeteo.kt` | forecast / geocoding URLs + parsing, `slice()` = the city's local "now" + 48 h, current folded into hour 0 (M14 / M16) |
| `domain/Sample.kt` | the built-in sample day (design sampleDayScript, virtual clock) and the 24 time-zone cities |
| `domain/Texts.kt` | every data sentence zh / en: time words, sky words, readout lines, tags, ring day names, advice rules ①–⑧ |
| `domain/Ring.kt` | 1€ filter, drag gain, inertia, whole-hour snap, hysteresis, stops + rebound, back-to-now animation |
| `domain/SceneModel.kt` | what the diorama shows for a ring position (clouds, precipitation, wind, sun / moon, light, snow) |
| `domain/Layout.kt`, `Pieces.kt`, `Mesh.kt`, `Math3.kt` | every metre; procedural meshes (lathes, clouds, sheets …) |
| `domain/WeatherFlow.kt` | the single state (S00–S11), fetch / cache / offline, ring, ask, cities, storm flash, sounds |
| `data/Stores.kt` | settings (prefs), cities.json, cache-<city>.json (atomic), HttpURLConnection Open-Meteo source |
| `ui/scene/*` | `DioramaScene` (entities, per-frame in `onFrame` via `DioramaFrameSystem`), `VolumeScreen` (input), `SceneKit` (meshes, textures) |
| `ui/control/*` | the window pages; every Text logs `OVERFLOW <tag>` when cut |
| `tools/` | `calibrate_models.py`, `import_sounds.py`, `build_icon.py`, `symbols.py`, `loudness.py`, `contrast.py`, `blank.py`, `ws.sh`, `shots.sh` |

Input (board-input template, `dragStartM` 1.2 cm): holders `ring` (32 invisible boxes around the band), `knob`, `sky`
(one box over the cloud layer), `tree`, `house`. A drag on `ring` turns time: the template's volume-axis x travel
(+X = right = later) x gain / R (controller / hand ray 1.0, eye-hand 2.5). Taps: knob = (re)open the control window,
sky / tree / house = a tag for 2.5 s.

## Build / test (kj-mbp-m5)
```bash
export JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.13+9/Contents/Home
./gradlew --offline assembleDebug :app:testDebugUnitTest   # JVM tests: advice rules, ring, Open-Meteo slicing, flow, bounds, scene model, hit replay
~/.factory-venv/bin/python tools/calibrate_models.py ; ~/.factory-venv/bin/python tools/import_sounds.py ; ~/.factory-venv/bin/python tools/build_icon.py --icon512 icon.png
DEV=<borrowed serial> tools/ws.sh install
```
Emulators are shared: borrow with `python3 -I bin/emu_borrow.py borrow weather-scape` in the factory, return after.

`tools/ws.sh cmd <cmd> [arg]`). Log tag `WeatherScape`. Every command calls the same WeatherFlow functions as the
